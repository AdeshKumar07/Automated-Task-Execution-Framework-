\# Automated Task Execution Framework



\## Project Structure

This repository allows you to access both the Frontend and Backend code for the application. The code is organized into separate branches:



\* \*\*Backend Code:\*\* Located on the \[backend](../../tree/backend) branch (Default).

\* \*\*Frontend Code:\*\* Located on the \[frontend](../../tree/frontend) branch.



\## How to Switch Branches

To view the frontend code, use the branch dropdown menu above or run:

`git checkout frontend`
